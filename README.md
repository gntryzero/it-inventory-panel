Учет сотрудников 

Веб-приложение для кадрового учета сотрудников в организации. 
Сделал в рамках учебной практики на PHP и MySQL.

Что умеет:
1. Показывает список сотрудников с полной информацией: ФИО, отдел, должность, паспорт, телефон, адрес проживания, зарплата, дата приема и текущий статус.
2. Считает статистику на главной странице (сколько всего сотрудников, сколько сейчас работают, сколько уволены).
3. Ищет по ФИО, паспорту или телефону.
4. Сортирует таблицу по клику на заголовки (ID, ФИО, Статус).
5. Делит записи на страницы (пагинация по 5 человек), чтобы таблица не растягивалась бесконечно.
6. Экспортирует базу в Excel (формат CSV с корректной кодировкой, чтобы русские буквы не превращались в кракозябры).
7. Ведет историю действий (кто, когда и что добавил, отредактировал или уволил).
8. Увольнение сделано через "мягкое удаление" (soft delete). То есть сотрудник не стирается из базы, а просто помечается как уволенный. Его строка становится серой и зачеркнутой, а кнопки редактирования пропадают.
9. В форме добавления есть маски на JavaScript. В ФИО нельзя ввести цифры, в паспорт нельзя ввести буквы (и пробел ставится сам), телефон автоматически форматируется в +7 (999) 123-45-67, а в поле зарплаты можно вводить только цифры.
10. Красивые цветные плашки для статусов (Зеленый - работает, Желтый - в отпуске, Синий - на больничном, Красный - уволен).

Как это запустить:

1. Качаем и ставим XAMPP (или OpenServer, но лучше XAMPP).
2. Открываем XAMPP Control Panel и жмем Start напротив Apache и MySQL. Должны загореться зеленым.
3. Скачиваем этот репозиторий как ZIP и распаковываем.
4. Папку с проектом кидаем в C:\xampp\htdocs. То есть путь должен быть такой: C:\xampp\htdocs\staff-app
5. Открываем в браузере http://localhost/phpmyadmin
6. Там сверху переходим во вкладку SQL. Открываем файл db.sql из проекта, копируем оттуда весь код, вставляем в это окно и жмем "Выполнить".
7. После этого у нас появится база staff_db с таблицами и тестовыми данными.
8. Открываем в браузере http://localhost/staff-app/index.php

Важно по базе данных:
Настройки подключения лежат в файле db.php. По умолчанию там стоит локальный хост, юзер root и пустой пароль. Это стандарт для XAMPP. Если у тебя на MySQL стоит пароль, то его нужно вписать в db.php, иначе выдаст ошибку подключения.

Если что-то не работает, скорее всего:
- Забыл запустить MySQL в XAMPP.
- Не импортировал db.sql в phpMyAdmin.
- Неправильно назвал папку (должна быть строго staff-app).
