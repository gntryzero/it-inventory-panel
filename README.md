IT Inventory Panel

Веб-приложение для учёта IT-оборудования колледжа. 
Сделал в рамках учебной практики на PHP и MySQL.

Что умеет:
- Показывает список всего оборудования (таблица).
- Считает статистику (сколько всего, сколько в работе, сколько списано).
- Ищет по названию, серийному или инвентарному номеру.
- Сортирует таблицу по клику на заголовки.
- Делит записи на страницы (по 5 штук).
- Экспортирует базу в Excel (формат CSV).
- Ведет историю действий (кто, когда и что добавил или списал).
- Увольнение сделано через "мягкое удаление" (soft delete). То есть запись не стирается из базы, а просто помечается как списанная.
- В форме добавления есть маска на JS, чтобы инвентарный номер сам подставлялся как INV-1234.

Как это запустить:

1. Качаем и ставим XAMPP (или OpenServer, но лучше XAMPP).
2. Открываем XAMPP Control Panel и жмем Start напротив Apache и MySQL. Должны загореться зеленым.
3. Скачиваем этот репозиторий как ZIP и распаковываем.
4. Папку с проектом кидаем в C:\xampp\htdocs. То есть путь должен быть такой: C:\xampp\htdocs\it-inventory-panel
5. Открываем в браузере http://localhost/phpmyadmin
6. Там сверху переходим во вкладку SQL. Открываем файл db.sql из проекта, копируем оттуда весь код, вставляем в это окно и жмем "Выполнить".
7. После этого у нас появится база equipment_db с тестовыми данными.
8. Открываем в браузере http://localhost/it-inventory-panel/dashboard.php

Важно по базе данных:
Настройки подключения лежат в файле connect.php. По умолчанию там стоит локальный хост, юзер root и пустой пароль. Это стандарт для XAMPP. Если у тебя на MySQL стоит пароль, то его нужно вписать в connect.php, иначе выдаст ошибку подключения.

Если что-то не работает, скорее всего:
- Забыл запустить MySQL в XAMPP.
- Не импортировал db.sql в phpMyAdmin.
- Неправильно назвал папку (должна быть строго it-inventory-panel).
